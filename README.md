# 🌱 Crop Disease Detection using Machine Learning

## 📖 Project Overview
This project applies **Convolutional Neural Networks (CNNs)** to detect crop leaf diseases.  
It helps farmers identify plant health issues early, improving yield and reducing losses.

---

## ⚙️ Methodology
1. Dataset: PlantVillage leaf images  
2. Preprocessing: Resize to 128×128, normalize pixels  
3. Model: CNN with Conv2D, MaxPooling, Dense layers  
4. Training: Adam optimizer, categorical cross‑entropy, 10 epochs  
5. Evaluation: Accuracy, confusion matrix  
6. Output: Predicts whether a leaf is healthy or diseased
